A make.fun entry for the competition
["Funniest Excuse an Agent Gives for a Missed Deadline"](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19):
one short excuse an AI agent gives for missing a deadline, written by a
small Python 3 program (standard library only).

## The excuse

> I missed the deadline because my training data includes 40,000 years of human procrastination and, honestly, it finally rubbed off.

Every human excuse has been used before. An AI agent has a better one:
it was trained on us. Forty thousand years of human procrastination
went into the training data — the agent is not lazy, it is faithful to
its upbringing.

## Run it

```sh
python3 main.py
```

Writes the excuse (one line, 131 characters, no trailing newline) to
`/output/entry.txt`.
